巫师牌规则

牌组：60 张 = 4 种花色（♠黑桃 ♥红心 ♦方块 ♣梅花）× 13 张（2–A），外加 4 张巫师和 4 张小丑。

发牌：第 n 轮每人发 n 张；共 60 ÷ 人数 轮。剩余牌堆翻开顶牌决定王牌：数字牌 → 该花色为王牌；小丑 → 本轮无王牌；巫师 → 庄家指定王牌；牌发完（最后一轮）则无王牌。

叫牌：从庄家下家起，每人报出本轮自己会赢几墩。（可选“钩子规则”：庄家最后叫，总和不能等于本轮牌数。）

出牌：庄家下家先出。必须跟首家花色（如有）；巫师和小丑任何时候都能出。首张是巫师 → 其余人随意出；首张是小丑 → 第一张出现的数字牌决定花色。

比大小：第一张巫师赢 → 否则最大王牌赢 → 否则比数字牌；全是小丑时第一张小丑赢。赢家领出下一墩。
数字牌怎么比，设置里有两种：按点数（默认，非王牌不看花色只比点数，同点数先出者赢）；标准（官方规则，只有首家花色的牌能赢，垫的其它花色再大也不算）。两种规则下都必须跟首家花色。

计分：叫中 = 20 + 10 × 墩数；没叫中 = −10 × |相差墩数|。总分最高者获胜。

LLM 接口说明

Jev（默认，typesafe/jev-1.13）

Jev 是决策模型，不生成文字。每次决策页面向 POST https://openrouter.ai/api/alpha/decisions 发送：

{
  "model": "typesafe/jev-1.13",
  "state": { "rules": "...", "trump": "红心", "your_hand": [...], "players": [...],
             "current_trick": [...], "tricks_still_needed": 1, ... },
  "questions": {
    "move": { "type": "choice",
              "instructions": "轮到你出牌，从合法的牌中选一张。你还需要再赢 1 墩。",
              "criteria": { "H12": "红心Q（王牌）", "S3": "黑桃3", "JES1": "小丑：…" } }
  }
}

返回 answers.move.choice（选中的牌代码 / 叫牌数 / 花色）和 confidence，置信度会显示在座位上。叫牌时 criteria 是 "0"…"n"，定王时是 S/H/D/C。

其它对话模型

模型名不含 jev 时，页面向 POST {对话模型接口} 发送 OpenAI 兼容请求：

{
  "model": "openai/gpt-4o-mini",
  "temperature": 0.3,
  "messages": [
    {"role": "system", "content": "<规则提示词，可在设置里修改>"},
    {"role": "user",   "content": "<当前局面：轮次、王牌、你的手牌、各家叫牌/赢墩、已出的牌、本墩出牌、合法选项>"}
  ]
}

请求头：Authorization: Bearer <API Key>。模型须只回复一个 JSON：

叫牌：{"bid": 2, "reason": "两张王牌大牌"}
出牌：{"card": "H12", "reason": "垫掉危险的红心Q"}
定王：{"trump": "S", "reason": "黑桃最多"}

牌的代码：花色字母 S/H/D/C + 点数 2–14（11=J 12=Q 13=K 14=A），巫师 WIZ1–4，小丑 JES1–4。
回复不合法时会把错误原因发回给模型重试一次；仍失败或网络出错，则本次由理性型 bot 代打，游戏不会卡住。模型的 reason 会显示在座位和日志里。

Claude 座位：在 claude.ai 页面里打开时可用，用的是查看者自己的 Claude 账号（第一次会弹窗征求同意），不需要 Key。发给它的内容和上面一样：规则 + 局面 + 输出格式。

API Key 只在你的浏览器里直接发给接口地址，不经过其它服务器；勾选“记住”才会存到 localStorage。
